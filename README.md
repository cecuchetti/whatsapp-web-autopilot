# Whatsapp-Web-Autopilot

**Whatsapp-Web-Autopilot** is a tool designed to automate the process of sending information through WhatsApp. The application provides functionalities similar to bulk messaging systems, offering features that streamline communication via the platform.

---

## Features

1. **Send messages to registered contacts**:  
   Messages can be sent to a predefined list of contacts using their names.  
   [![Whatsapp Automation](https://img.youtube.com/vi/3JttBmQHLQo/0.jpg)](https://www.youtube.com/watch?v=3JttBmQHLQo)

2. **Send messages to unregistered numbers**:  
   The tool supports sending messages to numbers not stored in the contact list.  
   [![Whatsapp Automation](https://img.youtube.com/vi/CDvbx--OfpI/0.jpg)](https://www.youtube.com/watch?v=YCDvbx--OfpI)

3. **Send images**:  
   Images can be sent directly through the application.  
   [![Whatsapp Automation](https://img.youtube.com/vi/wHnEWmsearI/0.jpg)](https://www.youtube.com/watch?v=wHnEWmsearI)
